## Final Project: Power Outage Prediction in West Virginia

### Project Goal
The goal of this project is to develop a machine learning system that can help notify users before a power outage occurs in West Virginia.

### Datasets Used
This project currently uses:

- **EAGLE-I**
- **NOAA Storm Events**

These datasets are being prepared and combined to support future model training and prediction.

### Current Progress
At this stage, the main focus of the project has been:

- cleaning the datasets
- merging multiple data sources
- preparing the data for future machine learning use
- generating reports and notebooks that document the data preparation process

The notebooks inside the project folder currently serve as:
- reports on the datasets
- notebooks used for cleaning and merging data
- preparation work for future model training and prediction

### Model Status
Model training has not started yet. The current phase of the project is focused on building a clean and usable dataset so that future machine learning models can be trained effectively.
